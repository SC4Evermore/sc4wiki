The **Daeley Advanced Menu Navigator**, usually abbreviated **DAMN**, is a tool created by [Daeley](/people/daeley) that creates an alternative menu system based on news message pop ups. The mod creates a folder structure in your program files/plugins directory where the DAMN definition files will be put, the in-game menu will then have the same hierarchy of the folder structure on your hard drive. Some sets are already included but for additional sets, somebody will have to create a DAMN definition file which defines the look of the news pop ups. A development kit for this modification was released to ease this process.
