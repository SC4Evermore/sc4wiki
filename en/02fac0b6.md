**02FAC0B6** is a file format used by [SimCity (2013)](/simcity-2013) to assign strings to pointers. It differs to [0A98EAF0](/0a98eaf0) in that **02FAC0B6** can only assign one string to a given memory address.

Its [DBPF](/dbpf) 3.0 [Type ID](/type-id) is **02FAC0B6**.
