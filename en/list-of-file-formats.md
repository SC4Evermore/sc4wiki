This is a (hopefully) complete list of all the file formats used by [SimCity 4](/simcity-4). Note that these file types are generally found *inside* [DBPF](/dbpf) files (such as .dat files). Some of them, however, can be freestanding files.

## Completely Decoded Files

[ATC](/atc) - Animation Texture Collection

[AVP](/avp) - Animation Viewpoints

[BMP](/bmp) - Bitmap

[Bridge RUL](/bridge-rul) - Complex bridge RULs.

[DBPF](/dbpf) - DataBase Packed Files

[Delocalizers](/delocalizers) - Text De-Localizers

[DBDF/DIR](/dbdf) - DBPF Directories

[FSC](/fsc) - Freshness Scores

[FSH](/fsh) - Franks PC Shapes (Textures)

[HIT](/hit) - Audio file format

[HLS](/hls) - Hitlist playlist

[ID](/id) - Radio ID

[INFO](/info) - Photo album info files.

[INI](/ini) - Initialization files, including the [Network INI](/network-ini).

[JPG/JPEG/JFIF](/jpg) - Joint Photographic Experts Group images.

[LDAT](/ldat) - Lot Data (LD)

[LTEXT](/ltext) - Language Text (LTEXT)

[LUA](/lua) - Lua programming language.

[PNG](/png) - Portable Network Graphics images.

[RUL](/rul-file) - Network Rules files, including [Bridge RULs](/bridge-rul).

[S3D](/s3d) - SimGlide 3D

[SC4Path](/sc4path) - SimCity4 Network Paths

[SGR](/sgr) - SimCity Graphics Rules

[KEYCFG/TAB](/keycfg/tab) - KeyCFG Accelerator Tables

[WAV](/wav) - Waveform Audio File Format

[XA](/xa) - Maxis EXtendable Audio

[XML](/xml) - XML files

## Incompletely Decoded Files

The following formats have yet to have their physical structures fully decoded:

[AB](/ab) - Audio Bank

[CFG](/cfg) - SimCity4 Startup Config

[MAD](/mad) - EA MAD Video

**[SAVEGAMES](/savegame)** - SimCity 4 Savegame files (.sc4), which themselves contain several additional unknown file formats.

The following formats have properties that have yet to be defined:

[AE](/ae) - U-Drive-It settings

[EFFDIR](/effdir) - Effect Resource Tree

[EXMP](/exemplar) - Exemplar

[TLO](/tlo) - Track Logic Object

[TRK](/trk) - Track Definition

[UI](/ui) - Maxis User Interface Definitions

## Other File Types

[HTML](/html) - HyperText Markup Language files - not found in DBPF files.

[MP3](/mp3) - Used for "radio station" music - not found in DBPF files.

[MXF](/mxf) - Used for in-game fonts - not found in DBPF files.

[TGI](/tgi-file) - Type Group Instance files - not found in DBPF files. For the definition of TGI, see [Type Group Instance](/type-group-instance).

[TXT](/txt) - Text files.
