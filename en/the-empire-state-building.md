**The Empire State Building** is a [Landmark Building](/landmark) in SimCity 4.

It provides no services aside from a Landmark Effect and Mayor Rating boost.

It is a recreation of the [Empire State Building](https://en.wikipedia.org/wiki/Empire_State_Building) in [New York City](https://en.wikipedia.org/wiki/New_York_City), completed in 1931.
