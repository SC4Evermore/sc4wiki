**0A98EAF0** is a file format used by [SimCity (2013)](/simcity-2013) to assign strings to memory pointers. It differs from [02FAC0B6](/02fac0b6) in that **0A98EAF0** can assign an array of strings to a memory address.

Its [DBPF](/dbpf) 3.0 [Type ID](/type-id) is **0A98EAF0**.

## SimCity

Used for String Definitions. Used to apply an array of strings to a single pointer.
