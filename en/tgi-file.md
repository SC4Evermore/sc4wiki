A **TGI File** is commonly found when you export files from a [DBPF](/dbpf) file. It is used by [Reader](/reader) to index a file when importing.

The structure is:

`Type ID`  
`Group ID`  
`Instance ID`

This file is plain text and can be opened in notepad (or alternative) and edited/created prior to reimportation by Reader.

This file *is not* contained within a [DBPF](/dbpf) file.
