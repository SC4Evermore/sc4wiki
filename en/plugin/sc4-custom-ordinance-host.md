The **Custom Ordinance Exemplar Host DLL** is a DLL plugin for [SimCity 4](/simcity-4) that allows new ordinances to be defined in ordinance exemplars. It is meant for modders.

## Features

- Each ordinance is an exemplar with its own instance ID.
- The source repository has a tutorial and example ordinances.
- Overrides of Maxis ordinances are ignored.

The game stores the ordinance properties in the save file. Tune an ordinance in a new city, or in a city you do not save. Ordinance DAT files go in `Documents/SimCity 4/Plugins/140-ordinances`.

## Requirements

- Windows 10 or later.
