The **NAM DLL** is a DLL plugin for [SimCity 4](/simcity-4) that improves how the game works with the [Network Addon Mod](/network-addon-mod) (NAM). The DLL is included in NAM 50.

## Features

- Enables Street tunnels. This needs a compatible tunnel and slope mod, such as the NAM Tunnel & Slope Mod.
- Adds keyboard shortcuts for the Monorail, One-Way Road, Dirt Road and Ground Highway network tools. Maxis left these partly implemented.
- Has an option to let zones develop along RHW networks. It is off by default.
- Version 1.4.1 adds a fix for dual transit route queries and support for network items in the Airport and Seaport menus.
- Each feature can be turned off in the `NAM.ini` file.

## Requirements

- SimCity 4 version 1.1.641 (the digital release), on Windows 10 or later, or Linux.

To use all its features, install NAM 50, which has network code made for the DLL. NAM is available in [sc4pac](https://memo33.github.io/sc4pac/channel/?pkg=nam:network-addon-mod) as `nam:network-addon-mod`.
