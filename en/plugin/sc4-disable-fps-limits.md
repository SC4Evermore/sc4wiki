The **Disable FPS Limits** DLL is a DLL plugin for [SimCity 4](/simcity-4) that removes the default frame rate limits at each simulation speed.

## Features

- By default, the game limits the frame rate to 30 FPS at Turtle speed, 20 FPS at Rhino speed and 15 FPS at Cheetah speed.
- The DLL lets the game run at up to 255 FPS at all simulation speeds.
- The `MaxFPS` setting in an INI file sets a lower limit if you want one.

## Requirements

- SimCity 4 version 641, on Windows 10 or later.
