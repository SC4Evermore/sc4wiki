The **More Building Styles DLL** is a DLL plugin for [SimCity 4](/simcity-4) that allows the game to use more than 4 building styles. It does not add any building styles by itself. Other mods that add new building styles need it.

## Features

- Removes the limit in the Building Style Control UI, which only knew the 4 Maxis styles.
- Adds a *Building Styles* exemplar property, so buildings can list custom styles apart from the Maxis styles.
- Adds a *Building Is Wall-to-Wall* exemplar property to mark W2W buildings.
- Lets styles be defined in `BuildingStyles.ini` or in Building Style exemplars, with tool tips for each style.
- Adds cheat codes, including the restored Maxis cheats `MaxisDebugRCIGrowth` and `MaxisIgnoreRCIGrowthCaps`.

## Requirements

- SimCity 4 version 641.
- Windows 10 or later, with the Microsoft Visual C++ 2022 x86 Redistributable. It may work on Windows 7 or later, but this is untested.
- A Building Style Control UI that shows the extra styles, such as the Building Style UI template on Simtropolis.
