The **Data View Extensions DLL** is a DLL plugin for [SimCity 4](/simcity-4) that extends the game's data views.

## Features

- Adds data view buttons for Moisture, Park Aura and Landmark Aura.
- An optional file adds a Transient Aura view. It replaces the Garbage Pollution view.
- The new UI otherwise matches the Maxis UI. It works with mods that reuse the Maxis data view buttons.
- Adds new data sources and highlight modes for data view modders.

Unlike Cori's Park Aura mod, it adds a new button and keeps the Garbage Pollution view.

## Requirements

- SimCity 4 version 1.1.641 (the digital release), on Windows 10 or later.
