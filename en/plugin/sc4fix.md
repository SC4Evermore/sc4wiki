**SC4Fix** is a DLL plugin for [SimCity 4](/simcity-4) that patches bugs in the game. Version rev8 is marked as a pre-release on GitHub.

## Features

- Fixes a save game bug that could corrupt the save. It mainly occurs with mods that change existing exemplars, which causes prop pox.
- Fixes a crash to desktop when you hover puzzle pieces over transit-enabled lots.
- Lets other DLLs load into the game's memory without a GZCOM framework.

## Requirements

- SimCity 4 version 640 (fully patched retail) or 641 (digital release), on Windows.
