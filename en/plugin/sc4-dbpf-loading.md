The **Startup Performance Optimization DLL** is a DLL plugin for [SimCity 4](/simcity-4) that optimizes the loading of plugin files when the game starts.

## Features

- Cuts the time before the SC4 logo appears by up to 90%.
- Reduces lag and city load times with many .SC4* plugin files.
- Allows file paths longer than the Windows limit of 260 characters.
- Loads only .SC4Desc, .SC4Lot and .SC4Model files and files without an extension. Other files, such as .txt and .png, are ignored.
- Decodes QFS-compressed data faster, which may improve city scrolling.

## Requirements

- SimCity 4 version 1.1.641 (the digital release), on Windows 10 or later.
- The [Microsoft Visual C++ 2022 x86 Redistributable](https://aka.ms/vs/17/release/vc_redist.x86.exe).
