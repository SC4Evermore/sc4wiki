The **Query UI Extensions DLL** is a DLL plugin for [SimCity 4](/simcity-4) that extends the query tool UI. Other DLL plugins can also use it to add their own query dialog data and tool tips.

## Features

- Shift + click on a building with the query tool to place the same lot. This also works for some flora.
- Adds new variables for building query dialogs, and a Lua function to read occupant exemplar properties.
- Extends the terrain query. Hold Alt for weather data, or Ctrl for pollution, land value and mayor rating.
- Adds advanced tool tips for flora, networks and props. Hold Control + Alt + Shift while hovering to see them.
- Can turn off the query sounds, and can log the plugin file path of a queried building.

## Requirements

- SimCity 4 version Windows 1.1.641.
- Windows 10 or later, with the Microsoft Visual C++ 2022 x86 Redistributable. It may work on Windows 7 or later, but this is untested.
