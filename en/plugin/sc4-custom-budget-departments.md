The **Custom Budget Departments DLL** is a DLL plugin for [SimCity 4](/simcity-4) that allows new budget departments to be added to the game with a building's exemplar. It is meant for modders.

## Features

- New departments can appear in any of the seven budget windows, such as Utilities or Public Safety.
- Each line item can be an expense or an income.
- Costs can be fixed. They can also vary with the residential population, the wealth groups or an estimate of tourism.
- A Lua function can calculate the cost.

## Requirements

- Windows 10 or later.
- The [Microsoft Visual C++ 2022 x86 Redistributable](https://aka.ms/vs/17/release/vc_redist.x86.exe).
