The **More Demand Info DLL** is a DLL plugin for [SimCity 4](/simcity-4) that adds game variables with more RCI demand information. Lua scripts and UI files can read these variables as `game.<variable name>`. It is mainly for modders.

## Features

- Adds demand variables for each commercial service wealth level and each industry type.
- Adds the current IR (agriculture) cap.
- Adds region population variables for each residential, commercial and industrial type.
- Adds the estimated monthly tax income for each RCI type.

## Requirements

- Windows 10 or later. It may work on Windows 7 or later with the Microsoft Visual C++ 2022 x86 Redistributable, but this is untested.
