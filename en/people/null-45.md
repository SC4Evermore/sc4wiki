**Null 45** is a modder who writes [DLL plugins](/dll-plugins) for [SimCity 4](/simcity-4). On GitHub, Null 45 publishes as [0xC0000054](https://github.com/0xC0000054). Since late 2023, Null 45 has released dozens of DLL plugins. They range from small fixes to frameworks that other modders build on.

Null 45 is the largest contributor to [gzcom-dll](https://github.com/SC4SDK/gzcom-dll), the open source SDK that many SimCity 4 DLL plugins use. Null 45 also made a GZCOM DLL plugin template for SimCity 4, and a similar framework for [SimCity 3000](SimCity 3000).

## DLL Plugins

Fixes and performance:

- [CPU Options DLL](/plugin/sc4-cpu-options)
- [Startup Performance Optimization DLL](/plugin/sc4-dbpf-loading)
- [Graphics Options DLL](/plugin/sc4-graphics-options)

Interface and tools:

- [Query UI Extensions DLL](/plugin/sc4-query-ui-hooks)
- [Data View Extensions DLL](/plugin/sc4-data-view-extensions)

Frameworks for modders:

- [Resource Loading Hooks DLL](/plugin/sc4-resource-loading-hooks)
- [More Building Styles DLL](/plugin/sc4-more-building-styles)
- [Lua Extensions DLL](/plugin/sc4-lua-extensions)
- [More Demand Info DLL](/plugin/sc4-more-demand-info)
- [Custom Budget Departments DLL](/plugin/sc4-custom-budget-departments)
- [Custom Ordinance Exemplar Host DLL](/plugin/sc4-custom-ordinance-host)

The [DLL Plugins](/dll-plugins) page lists more DLLs by Null 45, such as the Auto Save, No Kick Out, Region Census and Extended Terrain DLLs. Many of them are also available in [sc4pac](https://memo33.github.io/sc4pac/) in the `null-45` group.
