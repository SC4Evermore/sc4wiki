**Simmaster07** is a modder who writes [DLL plugins](/dll-plugins) and other technical mods for [SimCity 4](/simcity-4). On GitHub, simmaster07 publishes as [nsgomez](https://github.com/nsgomez).

In 2012, simmaster07 started [gzcom-dll](https://github.com/SC4SDK/gzcom-dll), an open source library that lets modders write DLL plugins in C++. It works like the [Extra Cheats DLL](/plugin/sc4-extra-cheats-dll) of the game. Today many SimCity 4 DLL plugins use it. Other modders, such as [Null 45](/people/null-45) and [CasperVg](/people/caspervg), have since expanded it.

## Mods and Tools

- [SC4Fix](/plugin/sc4fix), a DLL plugin with third-party patches for bugs in the game. It fixes a save game bug that could cause prop pox. Work on it started in 2015. The last full release is rev7 (January 2018).
- [SCGL](/plugin/scgl), an OpenGL 3 renderer for the game. Version 1.0.0 was released in February 2026.
- [SC4 Mac Injector](https://github.com/nsgomez/sc4macinjector) (2017–2018), a proof of concept that let SimCity 4 for Mac load extra libraries.
- [Scion](https://github.com/nsgomez/scion), a work-in-progress reimplementation of the Maxis game engine that The Sims 2 and SimCity 4 use.

## Earlier Activity

Simmaster07 created the [UD Productions](/ud-productions) website called UDPX Central. The site also hosted the [No Name Maps](/no-name-maps) Team and AFDES. The site is no longer online.
