The **Dependencies List** is a list created by [Diggis](/people/diggis) that lists every Dependency Pack available, and thus allows you to easily find the [dependencies](/dependency) a lot requires. Both a .pdf and a .html version are available of the 2007 version of the list. However, the 2007 version is obsolete and not linked here. The list was last updated in May 2008, and is consequently outdated, but still contains valid links to most of the dependencies out there.

The current dependency list can be found [here](http://sc4devotion.com/forums/index.php?page=4).
