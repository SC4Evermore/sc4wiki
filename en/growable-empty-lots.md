A **growable empty lot** occurs when a [lot](/lot) grows without its building. Typically, the lot's textures and props still show up, just not the building itself. The source of this bug has been traced to RalphaelNinja's Plopable RCI Blank Lot Set, released in August 2003. Plugins that were created using this set of lots have a tendency to display this bug.

A list of plugins known to display this bug, as well as further information on how to fix the bug if you encounter it, can be found [here](http://sc4devotion.com/forums/index.php?topic=907.0).
