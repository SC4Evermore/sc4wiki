**Power** is one of the main utilities that a lot will need in order to [grow](/growable). It can be supplied by a [power plant](/power-plant) (for example the [windmill](https://en.wikipedia.org/wiki/windmill) or [nuclear plant](https://en.wikipedia.org/wiki/nuclear_plant)) and transported by using the [overhead power lines](/transit-network#powerlines). If there is no [power](/power) supplied to a building, it will display the [power zot](/zot). Zones and buildings (including parks) also carry power, so there is no need to connect every zone to a transmission line as long as the zone is close enough to another zone or building that has power.
