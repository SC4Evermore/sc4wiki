The **Villa** is a High-Wealth Residential Building with three statistically Identical Variants that grow on All Residential zones.

## Variant Differences

All variants have exactly the same properties, grow on the same lots and use exactly the same base model using different exterior textures to establish variety.

[The Grabrians](/the-grabrians) can be considered to be a fourth variant, as it uses the same base model and is in the same IID range.
