**ID** is the channel identification format used by [SimCity 4](/simcity-4)'s radio stations to locate the proper directory in which to find the songs that belong to that radio station. It is a container format that is just an empty file. The two such files are kmay.id and krgn.id, and are located in SC4's Program Files directory, in the radio station subfolders. ID files are not found within [DBPF](/dbpf) files. One might note that the two stations, KMAY and KRGN, keep with the longstanding Maxis tradition of using Western US radio naming conventions for the game's radio stations (for example, the ubiquitous KSIM).
