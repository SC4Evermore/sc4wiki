An **HTML** file is used to create [webpage](https://en.wikipedia.org/wiki/webpage)s, and is also used for many [ReadMe](/readme)'s for Custom Content.

Its [DBPF](/dbpf) 3.0 [Type ID](/type-id) is **DD6233D6**.

## SimCity 4

[SimCity 4](/simcity-4) does not use HTML files itself.

## SimCity

[SimCity (2013)](/simcity-2013) uses HTML5 standard HTML files, possibly used for the game's Webkit-based User Interface. There are no other known uses.
