## Developer CAPS

There are four **Developer CAPs** available for all developer types, telling which stage is the highest one allowed to develop without supplying what is capped. The four caps are as follows:

1.  Power Cap - Determines the highest stage building that will develop without power.
2.  Water Supply Cap - Determines the highest stage building that will develop without water.
3.  Fire Coverage Cap - Determines the highest stage building that will develop without requiring that the site be within the coverage radius of a fire station.
4.  Park Cap - Determines the highest stage building that will develop without requiring that the site be within 20 tiles of a park.

### Without CAM

The Developer CAPs are as follows:

1.  Power Cap - Set to 0 (zero) for all types (nothing will develop without power).
2.  Water Supply Cap -
    - This is set at 0 for R\$\$\$, CS\$\$\$, CO\$\$\$ and I-HT
    - This is set at 1 for I-D and I-M
    - This is set at 3 for all other types (unused for IR, in other words)
3.  Fire Coverage Cap - Set to 9 for all types (unused, because there is no stage 9 without CAM).
4.  Park Cap -
    - This is set at 3 for R\$\$\$
    - This is set at 9 for all other types

### With CAM

The Developer CAPs are as follows:

1.  Power Cap - Set to 0 (zero) for all types (nothing will develop without power).
2.  Water Supply Cap -
    - This is set at 0 for R\$\$\$, CS\$\$\$, CO\$\$\$ and I-HT
    - This is set at 1 for I-D and I-M
    - This is set at 3 for all other types
3.  Fire Coverage Cap -
    - This is not used for R\$, CS\$, CS\$\$, CO\$\$
    - This is set at 3 for I-HT
    - This is set at 4 for I-R
    - This is set at 5 for I-D and I-M
    - This is set at 9 for R\$\$\$
    - This is set at 12 for R\$\$, CS\$\$\$, CO\$\$\$
4.  Park Cap -
    - This is set at 3 for R\$\$\$
    - This is set at 5 for I-R
    - This is set at 6 for I-HT
    - This is set at 9 for R\$\$, CS\$\$\$, CO\$\$\$
    - This is set at 12 for R\$, CS\$\$, CO\$\$
    - This is not used for CS\$, I-D, I-M

### Notes

The following notes were included in the original post from which this article is derived:

"During CAM testing of the farming stages mentioned in posts above, I left the water supply cap at 3. Thus, I had to supply water for the farms to develop above stage 3. I also tested to leave an area of farms without water and didn't get anything higher than stage 3 to develop there.

For the final Stages 9-15 mod we need to decide how to set these caps."
