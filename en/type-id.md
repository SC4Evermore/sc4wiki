The **Type ID** (**TID**) of a [DBPF](/dbpf) Object is the first set of eight [hexadecimal](/hexadecimal) numbers making up the object's [Type Group Instance](/type-group-instance) (TGI) address. As an example, in the TGI "AAAAAAAA BBBBBBBB CCCCCCCC", the sequence "AAAAAAAA" is the object's TID. They are used in [SimCity 4](/simcity-4) and [SimCity (2013)](/simcity-2013) to organize related objects of the same file type, which are then further defined by use of the [Group ID](/group-id) and [Instance ID](/instance-id).

### Common Types

Some of the common Type ID's used in SC4 are:

| Type ID | Description |
|----|----|
| 05342861 | [Cohorts](/cohort) - higher level exemplars. |
| 5ad0e817 | [S3D](/s3d) - A type of graphics file. |
| 6534284a | [Exemplars](/exemplar) - files that contain important game-defining properties. |
