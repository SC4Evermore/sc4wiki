**CityMania** is a new project started on February 3rd, [2009](/2009), aiming at the creation of an [Open Source](https://en.wikipedia.org/wiki/Open_Source) [SimCity 4](/simcity-4) clone. The development is headed by [Nique](/people/nique), and aided by [JoeST](/people/joest). At first, it was named *Open SimCity*, but the name was later replaced by *CityMania*, to make sure there were no copyright issues. So far, there have been some development shots regarding the terrain, and a few key UI elements have also been created. Currently, plans are to create the application using [C#](https://en.wikipedia.org/wiki/C%23) and [DirectX](https://en.wikipedia.org/wiki/DirectX).

[Nique](/people/nique) was last active on SC4Devotion on March 29, 2015.
