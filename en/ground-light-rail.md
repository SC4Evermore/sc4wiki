**Ground Light Rail** is a [NAM](/nam) project, that includes a [PuzzleDrag](/puzzle-piece) approach, that allows you to use [trams](https://en.wikipedia.org/wiki/trams).

It uses the same paths as the [Maxis](/maxis) [Elevated Rail](/transit-network#elevated-rail) and is thus an extension of the [Elevated Rail](/transit-network#elevated-rail), so links between the two can be made using the puzzlepieces included in the [NAM](/nam). Sometimes [subway](/transit-network#subway) is mistaken for using the same paths as Light Rail but this is not the case and subway is an entirely separate network. Some parts of it, namely the *GLR-in-Network-pieces*, were recently relocated under the name [T-RAM](/t-ram).
