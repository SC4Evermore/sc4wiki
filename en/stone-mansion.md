The **Stone Mansion** is a High-Wealth Residential Building with four statistically Identical Variants that grow on All Residential zones.

## Variant Differences

All variants have exactly the same properties, except for the Bulldoze cost on Variant 4 which is §30 cheaper, and grow on the same lots.

All variants use exactly the same base model, using different exterior textures to establish variety.

[The Bachman-Wood Building](/the-bachman-wood-building) uses almost the same model, differing only by having different stairs on the front of the building.

## Reference Buildings

Stone Mansion is likely based on [Bolling Haxall House](https://en.wikipedia.org/wiki/Bolling_Haxall_House) in [Richmond](https://en.wikipedia.org/wiki/Richmond%2C_Virginia), [Virginia](https://en.wikipedia.org/wiki/Virginia), built in 1858. Aside from a few errors, it is an accurate recreation of the building prior to its 1916 extension.
