On a standard installation, there are two [plugin](/plugins) directories, the My Documents Plugins folder and Program Files Plugin Folder.

If you have more than one user on your computer then the plugins in the My Documents Plugins folder are for each user while the Program Files Plugin folder is shared between all users on the computer.
