WAV files are uncompressed audio files.

Its [DBPF](/dbpf) 3.0 [Type ID](/type-id) is **0D9E5710**

## SimCity 4

[SimCity 4](/simcity-4) does not use WAV, its equivalent is [XA](/xa).

## SimCity

[SimCity (2013)](/simcity-2013) uses WAV to store its sound files. These have been encoded using an unknown codec or have been encrypted.

More information about the file format itself can be found [here](https://en.wikipedia.org/wiki/WAV).
