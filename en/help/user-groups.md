This wiki has special user groups which will be more familiar than the default user groups because they are similar to the different user groups in use on most forums.

N.B. Patrolling - when an edit is made, it will be marked as 'unpatrolled' (red exclamation mark in recent changes) and until someone who has the ability to 'patrol' can mark it as legitimate.
