The **Stone Chateau** is a High-Wealth Residential Building with three[^1] statistically[^2] Identical[^3] Variants that grow on All Residential zones.

## Variant Differences

All variants grow on the same lots and use roughly the same base model using different exterior textures and mirroring to establish variety.

All three variants are statistically identical with each other and [Baritone Palazzo](/baritone-palazzo), which can be thought of as an additional variant of this building.
