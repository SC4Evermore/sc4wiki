City Data file: 89EFA536

Below are the **Data Source IDs** found/used in the [Historical Graphs](/historical-graphs) file. Some IDs may exist but aren't listed below for whatever reason, some may only appear in a file when certain things are triggered. All of the known ones should now be here in this list.

## Format of Name List Below

DataSourceID Name/Label (a majority of the names/labels are names from the game itself).

`Data Source ID X - in Hex form as it appears in the Saved Game file.`  
`Data Source ID X - Same as above, except this is as it would/might appear in`  
`                   an Exemplar file (and/or possibly elsewhere) but without the "0x" at the beginning.`

Some known items could probably/possibly be grouped together and/or organized a bit better for our own purposes.
