## Proceeding Through The Installer

The first installation screen you will encounter is the "Welcome" screen. Click "Next" to continue the installation process.

You will then be brought to the NAM's License Agreement, which you must accept to continue.

The third page of the installer contains an exhaustive series of notes pertaining to NAM installation and system requirements, which describe some of the options.

After this page, you will be asked to choose an installation type. There are four options:

- **Traffic Simulator and Maxis Fixes Only**

<!-- -->

- **Networks and Traffic Simulator**

<!-- -->

- **Complete Standard Installation**

<!-- -->

- **Custom Installation**

These four options are detailed below, under Installation Types.

After selecting an installation type, you will be asked to choose the installation path for the NAM. The NAM installer is programmed to automatically select the default Plugins directory for your system, but if you have changed this in a previous NAM installation, the mod should recognize this and choose your alternate directory.

If you selected the Custom Installation option, you will subsequently be taken to the Choose Components page, where you will be able to pick which features will be part of your NAM installation. Otherwise, you will skip this page.

At this point, in all installation types, the next page will be the Confirmation page, where you will be given a summary of what components will be installed. The next button you click will be the "Install" button, which will begin to install the NAM on your computer.
