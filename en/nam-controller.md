The **NAM Controller** is a dat ([DBPF](/dbpf)) that contains 3 [RUL Files](/rul-file), and an [LTEXT](/ltext) shows the version number of the controller. It is main core of the [NAM](/nam) and without it the NAM is useless. Only one of each type of RUL can exist in the game, the game will use whichever RUL File loads last. The 3 RUL files are:

- [RUL 0x10000000](/rul-0x10000000)
- [RUL 0x10000001](/rul-0x10000001)
- [RUL 0x10000002](/rul-0x10000002)
