**Building Style Control** is a toolbar, introduced with the [Rush Hour Expansion Pack](/rush-hour-expansion-pack), that allows setting the architectural tone of new development (existing buildings are not affected). There are four styles of architecture to choose from, each of which correspond to a particular [tileset](/tileset) of buildings:

- [Chicago](https://en.wikipedia.org/wiki/Chicago) 1890
- [New York](https://en.wikipedia.org/wiki/New_York) 1940
- [Houston](https://en.wikipedia.org/wiki/Houston) 1990
- [European](https://en.wikipedia.org/wiki/European) Contemporary

You can either select one style that can be used, or you can use the *Change building style after X years* option, which cycles through the building styles after a number game years.
