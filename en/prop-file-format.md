The **PROP (Properties)** is a file format used in Spore and [SimCity (2013)](/simcity-2013). The SimCity 4 equivalent are [Exemplars](/exemplar)

Its [DBPF](/dbpf) 2.0/3.0 [Type ID](/type-id) is **00B1B104**.

## Spore

Stores properties about the game assets. Details unknown.

## SimCity

Stores properties about the game assets. Details unknown.
